## 主な変更内容

### 1. 新規ページの追加

**日本語版（`ja/`）・英語版（`en/`）のセットで追加**

#### `ja/about.html` / `en/about.html`（新規作成）
- 旧 `index.html` に混在していた「団体理念・Ubuntureについて・Mission」セクションを独立したページとして切り出した
- サブページヒーローバナー（`hero--about`）を配置
- ページ固有の OGP メタタグ（og:title・og:description・og:url）を設定
- パンくずリスト（`breadcrumbs`）を追加

#### `ja/message.html` / `en/message.html`（新規作成）
- 代表・澤近大地のプロフィール、経歴タイムライン、10章構成のストーリー（代表の想い）、現地コーディネーター（笠井凜心）の紹介を収録
- サブページヒーローバナー（`hero--message`、背景: `world-travel-9872747_1280.jpg`）を配置
- 高校時代の4つの実績を「mini-card」グリッド（PC版2列）で表示
- スマホ表示時は「写真 → 小テーマ → 本文」の順番に自動調整（`flex-direction: column-reverse` + `:has()` セレクター使用）

#### `ja/news.html` / `en/news.html`（新規作成）
- 最新情報・活動報告の記事一覧ページ
- Newsスライダー（後述）と連動

#### `ja/project.html` / `en/project.html`（新規作成・大幅拡充）
- 南アフリカでのアンプラグドICT教育の活動詳細ページ
- ヒーローカードとミニカードによるビジュアル構成

#### `ja/support.html` / `en/support.html`（新規作成）
- 企業・団体向け支援と個人サポータープランを掲載するページ

#### `ja/team.html` / `en/team.html`（新規作成）
- メンバーおよびサポーターの紹介ページ

### 2. 既存ページの大幅リファクタリング

#### `ja/index.html` / `en/index.html`
- 旧トップページに詰め込まれていた「団体理念・代表プロフィール・各活動紹介」のセクションを削除し、各サブページへ移管
- トップページは「テイザー（見どころ紹介）」として各サブページへの誘導に特化したレイアウトに再構成
- 代表の想いセクションの「More」ボタンのリンク先を `about.html` から `message.html` へ変更
- `Home` ナビリンクに初期 `active` クラスを付与し、トップページ表示時から下線が表示されるよう修正

#### `ja/about.html` / `en/about.html`（旧ファイルの整理）
- 代表メッセージ・プロフィール・現地コーディネーター紹介のセクションを削除し `message.html` へ移管
- 団体理念のコンテンツのみに絞ったスリムなページへ整理

### 3. ナビゲーション（全ページ共通）

- すべての HTML ファイル（日英 各7ページ = 計14ファイル）のヘッダー・フッターナビに **「Message」リンク** を追加
- フッターナビのリンクパスを同一ディレクトリからの相対パス（`./about.html` 等）に統一
- 各ページで対応するナビアイテムに `class="active"` を設定し、現在地がわかるよう対応

---

### 4. モバイル対応ハンバーガーメニュー（`assets/js/main.js` / `assets/css/styles.css`）

- 既存のシンプルなトグルから、アニメーション付きハンバーガーメニューへ刷新
  - 開く: 1本目が右45°回転、2本目がフェードアウト・縮小、3本目が左45°回転（× 形状）
  - 閉じる: 逆アニメーションで3本バー形状に戻る
- メニュー開閉時の高さを CSS 変数 `--ul-height` で動的に制御し、スムーズなスライドアニメーションを実現
- モバイルでメニュー項目をクリックした際、`--ul-height` をリセットしメニューを閉じる処理を修正

---

### 5. Newsスライダーの追加（`assets/js/main.js` / `assets/css/styles.css`）

- `#news-slider` に対応するスライダーウィジェットを新規実装
- **主な機能:**
  - 前後ボタン（`prev` / `next`）でのスライド操作
  - ドットインジケーター（クリックで任意のスライドへジャンプ）
  - キーボード操作（← →矢印キー）
  - スワイプ（タッチ・ポインター）操作（しきい値 40px）
  - ビューポート幅に応じた表示枚数の自動計算（`getVisibleCount()`）
  - 1行に全カードが収まる場合はボタン・ドットを非表示（`no-slide` クラス）
  - `pointercancel` / `touchcancel` イベントのハンドリングを追加し、スクロール中断時の誤操作を防止
  - `resize` イベントで表示枚数を再計算し、スライド位置をリセット

---

### 6. スライダー（トップページ）の修正（`assets/js/main.js`）

- スライドのトランスフォーム計算をパーセンテージ基準（`-index * 100%`）からピクセル基準（`-index * viewport.clientWidth px`）へ変更し、ギャップ（CSS `gap`）がある場合でも正確な位置に移動するよう修正
- `resize` イベントでスライド位置を自動更新

---

### 7. CSSデザインシステムの拡充（`assets/css/styles.css`）

#### ナビゲーション
- ナビリンクのアクティブ下線: `::after` 疑似要素 + `scaleX()` アニメーション（`cubic-bezier(0.4, 0, 0.2, 1)`）で滑らかに伸縮
- ホバー時のスケールアップ（`transform: scale(1.1)`）
- モバイルメニューのグラスモーフィズム表現（`backdrop-filter: blur(10px)` + `rgba(255,255,255,.92)`）

#### サブページヒーロー
- `.subpage-hero` クラス: サブページ共通の全幅バナーセクション
- 各ページの背景画像マッピング:
  - `hero--about` → `about.jpg`
  - `hero--message` → `world-travel-9872747_1280.jpg`
  - `hero--project` → `project-1.jpg`
  - `hero--team` → `story9.png`
  - `hero--news` → `news-1.png`
  - `hero--support` → `project-2.jpg`

#### Messageページのカードグリッド
- `.mini-card` の4枚を2列×2行のグリッドに配置（PC版）
- `grid-template-rows: repeat(2, 1fr)` で上段・下段の高さを完全に統一
- カード内オーバーレイを上揃え（`justify-content: flex-start`）に変更し、タイトル開始位置を統一
- `h4 { margin: 0 }` を追加しブラウザデフォルトマージンによるずれを防止

#### スクロールアニメーション
- `.reveal` クラスによるフェードイン + スライドアップ表示の IntersectionObserver 実装

#### Newsスライダーのスタイル
- `.news-slider` / `.news-viewport` / `.news-track` / `.post` / `.news-btn` / `.news-dots` の新規スタイルを追加
- 全幅対応のレスポンシブレイアウト

#### グローバル修正
- `figure { margin: 0 }` を追加し、ブラウザデフォルトのマージンによるレイアウトずれを修正
- `--shadow-3` トークンを追加

---

### 8. アクティブナビ下線の修正（`assets/js/main.js`）

- IntersectionObserver によるアクティブリンク切り替えのロジックを修正
- **修正前:** 常にスクロールでアクティブ状態をトグルしていたため、トップページ表示時に `Home` の下線がスクロールで消えることがあった
- **修正後:** ナビメニュー内に `#` で始まるアンカーリンクが存在する場合のみトグルするよう条件分岐を追加。サブページ構成では `Home` の下線が常時維持される

---

### 9. 現地コーディネーター経歴文の改善（`ja/message.html`）

- 経歴の一文目（ALA留学中）が単独の段落として冒頭に置かれ、`<br>` タグによる空白が生じていた問題を修正
- 文体を敬体（〜しています）から**常体（〜している）** に統一
- 経歴を時系列順（生まれ → コロナ禍 → 各活動 → 留学）に再整理し、ALA留学の記述を末尾に移動

---
